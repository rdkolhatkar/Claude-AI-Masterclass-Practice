Reading and Writing Excel data with Claude and MCP server
1) In this test we are going to automate read and write operations for Excel sheet data using Claude and MCP
2) Referance Link : https://github.com/negokaz/excel-mcp-server
3) Configure the MCP server details in "claude_desktop_config.json" file and resart the claude
4) Here we don't need to worry about how claude will read the Excel file because for that we already have an existing MCP called "File System MCP Server"
5) If you don't have the File System MCP then Install "File System MCP Server" so that claude can access the Excel files from the local System.
6) Now Create a new excel file called "Test.xlsx" in the location where your File System MCP Path is configured with claude. In our case I/O path is "C:/Users/Ratnakar/Documents/Claude/Files/api-data-files"
7) Now everything is ready and you can give the Promot with instructions of Excel operation. Refer below example.
